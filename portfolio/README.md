# Shaista's Coquette Developer Portfolio

A responsive personal portfolio built with React and Vite. The design uses a soft blush-pink palette and CSS illustrations instead of photos.

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Before publishing

- Replace `hello@example.com` in `src/App.jsx` with your email.
- Replace the generic GitHub and LinkedIn profile links with your own URLs.
- Update project descriptions to match your real work.

## Deploy

Push this project to a GitHub repository, then import that repository into Vercel. Use the default Vite settings: build command `npm run build`, output directory `dist`. Add your live URL here after deployment.
